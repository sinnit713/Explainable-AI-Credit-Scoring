# R Scripts

This directory contains the R scripts used in the credit-risk modelling and explainability research.

## Script Overview

| Script | Purpose |
|---|---|
| `01_data_preparation.R` | Dataset cleaning, special-value handling, feature engineering and preparation |
| `02_models_and_metrics.R` | Logistic Regression, Random Forest and XGBoost modelling, tuning and performance evaluation |
| `03_robustness.R` | Bootstrap-based AUC equivalence testing, repeated partitions and preprocessing sensitivity analysis |
| `04_shap_analysis.R` | SHAP-based global and local explanations, feature agreement and explanation stability |
| `5_threshold_analysis.R` | Approval-rate simulations and comparison of lending decisions |
| `06_figures_and_tables.R` | Generation of research figures and summary tables |

## Execution Order

The scripts are organised to reflect the main stages of the research workflow, beginning with data preparation and ending with results visualisation.

## Requirements

The scripts use R and several packages for data manipulation, statistical modelling, machine learning, explainability and visualisation.

Refer to the individual scripts for their package dependencies and implementation details.
